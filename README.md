**The World in One Day — 17 November 2026.** A single-image summary of the world news of Tuesday 17 November 2026, typeset as an editorial front page: Ukraine strikes the Crimea Bridge as Russia hits Kyiv's bridges, the U.S. strikes Iran's Qeshm Island, the first Trump-Xi-Putin trilateral summit is set for Shenzhen, the U.S. loses its measles-free status after 26 years, tech outages reach the NSA, and GTA VI arrives after a 13-year wait. The Python program copies the poster to /output/entry.png, deterministically and offline.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

writes `out/entry.png` — the same bytes on every run, no network needed.
